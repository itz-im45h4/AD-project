# Technical Report Material

This folder holds source material for the 8–12 page technical report; the final submitted PDF can be produced separately.

Use these existing project artifacts as report evidence:

- `../architecture.md` — service/data boundaries and architecture rationale.
- `../sequence-ride-booking.md` — synchronous and asynchronous communication sequence.
- `../contracts/` — REST conventions and `PaymentRecorded` event contract.
- `../testing/` — test plan and integrated workflow evidence.

The report must also cover the monolith comparison, framework choice, security approach, CI evidence, limitations, and the primary-owner contribution statement for every member.
