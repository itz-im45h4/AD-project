# RideLink Build Root

Run all Maven commands from this directory:

```bash
./mvnw --batch-mode verify
```

The full project guide, ownership table, configuration instructions, and collaboration workflow are in the repository-level [`README.md`](../README.md). Shared diagrams, contracts, testing evidence, and report material are in [`docs/`](docs/); Postman assets are in [`postman/`](postman/).
